维护方式

自主爬虫默认开启，不需要 AI Key：从内置电视台网站发现频道，也会自动读取公开 GitHub / GitLab / 极狐仓库目录，发现 TXT / M3U 节目单；解析网页、脚本和公开播放器请求，抽检媒体后收录。每轮最多读取 20 页、解析 3 个播放器；进度会保存。电视需开机联网。待机、省电或强制停止应用可能推迟任务，重新打开 APP 会补查。

AI 维护助手

找源工具全部内置，无需部署服务或另配搜索密钥。停止播放、进入后台后自动查找；返回观看时暂停后续查找。官方 DeepSeek 自动使用原生联网搜索，并轮换央视、卫视与各地频道主题。每日最多 12 次找源 / 连接测试请求，搜索还可能产生服务商内部调用费用；图片巡检额度另计。

沿用原 API 地址和密钥即可。官方 DeepSeek 会自动接入原生联网搜索；其他 Chat Completions 服务保留网页搜索筛选方式。必须使用 HTTPS。

密钥加密存储在电视中，不会回显。

自动补齐真实台标

常用央视和卫视内置 120 个台标原图，其他频道从公开台标库补齐；节目单原有图片地址会保留。停止观看后自动下载并缓存，不需要 AI 密钥或模型请求。频道名称通过明确别名匹配，央视 5 与央视 5+ 分开。失败图片 24 小时后重试，已缓存图片每周检查更新；达到容量后先清理较旧的下载图片。找不到时显示备用电视图标，频道名称另行显示。台标只显示在节目列表和节目提示，不会覆盖视频或影响广告巡检。

扩展直播来源

不限 GitHub。可填电视台公开页面、公开直播列表或自己维护的订阅。发现 GitHub / GitLab / 极狐的仓库或 raw 链接后，会自动读取目录中的其他 TXT / M3U 文件；支持分批续查和去重，不需手动逐个导入。初始入口用于启动发现，不等于搜遍互联网。公开播放器可通过内置网页组件执行脚本并解析请求；不需要额外部署。动态地址会检查媒体及 M3U8 更新，画面和台标由巡检继续验证。需要登录、专网或 DRM 授权的源不保证可用。

屏蔽广告或错误线路

也可在电视里屏蔽当前播放线路。电视台节目本身的广告无法保证去掉。

黑屏或失效线路：在电视源维护页点击“检测并移除无效线路”。连续 3 次间隔检测失败才移除；“查看 / 恢复已移除线路”可撤销。此检测不调用 AI，不消耗模型额度。

仅在可信家庭 Wi‑Fi 中操作。本地网页使用 HTTP，不等同于端到端加密连接。

台标与纯广告画面巡检在电视维护页打开，DeepSeek 模型请用 deepseek-flash。截图会发给所配置的 API，图片识别有独立每日限额和费用；默认两轮新证据确认无台标纯广告后自动屏蔽，可在电视关闭自动屏蔽。
