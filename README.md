# 看电视 · KanDianshi

基于 [lizongying/my-tv](https://github.com/lizongying/my-tv) 的 Android 电视直播播放器分支，当前版本 1.14.2。保留遥控器操作界面，加入公开节目单、空闲维护、线路检测、可恢复的广告屏蔽和真实台标。

## 1.14.2 更新（2026-11-09）

- 修复 CCTV1、CCTV6 优先线路失效的问题。内置 7 条已直连检查视频轨道的国内候选，健康记录仍可覆盖启动顺序；沿用每6小时订阅更新及逐条验证机制，失败保留原列表。
- 单条首帧等待15秒、前台解码器等待3秒、单频道首轮加载总计45秒。节目单刷新不能重开已经终止的同台加载，明确点击重试或重新进入播放再开启新一轮。
- 对设备不支持的MPEG Layer II音轨增加纯Java解码回退，原生解码优先，队列和输入均有上限，不写入临时音频文件。JLayer许可证、原始包和对应源码随工程提供。
- 根据完整PAT/PMT拒绝明确只有音频的TS，不将“收到数据”当作电视画面可用；缺少或分段的表保持未知。
- 348项单元测试和Lint通过。实际release在API25模拟器直接点击原始节目单中的CCTV1→CCTV6→CCTV1，各持续解码12秒并截图、检查音轨；另外通过坏源超时、切线和节目单刷新不重复加载的运行测试。Android16/小米15Pro及电视实机未连接验证。

## 1.14.1 更新（2026-11-08）

- 修复当前地址非空时，点击其他频道没有发起播放的问题；点击同一失败频道可重新尝试全部线路。
- 修复节目单更新替换频道对象后，备用线路切换依赖旧观察者而停止的问题。刷新后重新关联当前频道；自动切备用线路由播放器直接执行。
- 增加加载／全部线路失败提示，以及不记录流地址和密钥的播放状态日志。
- 实际 release APK 在 API 25 模拟器完成 HTTP 视频出帧、播放中换台、黑屏后换台、脱离列表观察者的备用线路切换、同台重试；浙江卫视与 央视新闻（CCTV13） 抽样直播均实际出帧并继续播放。Android16、小米15Pro及电视实机尚未验证，不承诺所有节目源可播。

## 1.14.0 更新（2026-11-08）

- 补齐 iptv-org/iptv 独立订阅管理。旧版已有中国区订阅；本版默认继续中国区，并支持从 250 项官方国家／地区目录中选择最多 5 项。电视“频道管家”和局域网扫码页面均可配置，也可立即安排同步。
- 每个已选地区跟踪官方发布的 M3U，每 6 小时更新、失败至少间隔 15 分钟重试；观看时每轮最多请求一个地区，缓冲时让行。更新失败保留已有频道，不清空列表。
- 国际频道按地区分组和区分同名台，保留官方列表中的台标与备用地址。新频道沿用逐条媒体验证、失败记忆和候选容量限制；已验证扩展最多 1024 条。支持选择范围，不承诺一次收录全球全部频道或所有地址持续可播。
- 取消选择的国际地区从列表隐藏，正在播放地址仍受保护；普通国内基础频道保留。PHP 原生解析、广告巡检和结构化记忆继续使用。

## 1.13.0 更新（2026-11-08）

- 原生解析用户提供的“重温经典”固定频道（30167），无需 PHP 网站。节目权限与调度接口正常成功后获取临时直播地址，沿用逐条直播验证，通过后才加入频道。
- 稳定频道标识用于健康、广告和记忆记录；带时效的真实地址只在内存缓存 5 分钟。直播清单重新加载时可自动刷新地址；播放出错至多主动刷新一次，再使用原有失败处理。普通频道不等待此解析任务。
- 前台播放、手动画面巡检及后台画面巡检复用同一个解析入口。保留 HTTPS 证书校验、固定接口范围、响应上限和失败冷却；不枚举其他资源或绕过服务拒绝。
- 此功能解决指定频道地址过期，不能自动发现所有频道；当前服务器成功不代表任意地区、时间或设备始终可播。见 docs/cwjd-integration.md。

## 1.12.0 更新（2026-11-07）

- 安卓原生读取采集工具的 `config.ini` / `subscribe.txt`，以及每行一个 URL 的订阅索引。支持旧版 `[Settings] subscribe_urls`、启停开关、换行和去重；注释中的示例地址不会采集。
- 内置 testtff/TV 的订阅配置入口与 Guovin/iptv-api 的订阅列表入口。当前新版默认列表为空时不编造地址；旧仓库 2025 年的生成节目单不设为默认频道。每份索引最多接收 24 个公开入口，沿用已有队列、失败冷却及请求上限。
- 识别采集工具仓库：读取订阅配置和一个首选生成结果，跳过模板、别名、黑名单和 RTP 配置。常见 GitHub 镜像订阅可还原到直接源地址，保留不同查询参数。修复路径双斜杠被折叠导致转发链接失效的问题。
- 所有发现结果进入候选队列，白名单也须逐条检查；沿用观看时轻量维护、缓冲时让行、失败记忆与合并写入。UA 等额外请求设置不导入，依赖特殊请求头的源不保证兼容。
- 本版为独立实现的订阅格式兼容与现有维护流程整合，不包含上游 Python / Selenium / Docker 运行环境；不是完整移植其全部引擎。见 [集成说明](docs/collector-integration.md)。

## 1.11.0 更新（2026-11-07）

- 观看时自动轻量同步：常驻服务约每 5 分钟轮转，串行验证少量候选和旧线路，不使用额外视频解码器。播放缓冲时暂停网络维护；截图广告巡检仍等空闲执行。
- 修复一份节目单只抽检前三个频道、一个通过就收录全部的问题；手动添加的订阅同样逐条检查。未验证候选不进入播放列表，旧版发现结果转入候选复检，基础频道保留。
- HLS 检查媒体清单是否持续更新、前后视频分片能否读取；404、停更和未知/加密格式分开处理。传输检查不等同于设备实际解码成功，实际播放反馈继续决定优先级。
- 真正出过画面的线路优先。失败线路分轮复核，有媒体网络正常证据且连续失败才可恢复地移除；已移除的线路冷却后再查，当前观看地址受保护。
- 列表同步保留当前有效流与播放位置；失败停止的旧线路不再被误保护，新线路可参与自动回退。
- 候选队列最多 1024 条，有失败冷却和空间回收；已验证列表与 MIME 元数据也有限额，继续复用 10 分钟普通状态合并保存。API 密钥与永久广告名单保存方式不变。

## 1.10.0 更新（2026-11-06）

- 默认开启带常驻通知的维护服务，退出桌面后仍分批发现频道、复核线路和处理广告。可在频道管家或通知中停止常驻；原周期任务保留作为兜底。
- 空闲批次之间休息 15 分钟；观看优先。Android 强行停止、关机、省电策略或服务运行限制仍可能中断任务；应用设置内有系统后台权限入口。
- 普通健康记录、搜索/巡检进度与近期记忆在内存合并，每 10 分钟批量保存；相同内容不重复写入。突然断电可能回退尚未保存的非关键进度；休眠时系统可能推迟批量保存。
- 永久广告名单、手动移除/恢复、密钥及调用额度保留即时持久化。巡检图片只在内存处理，不新增视频录制或截图文件缓存。
- 参考 awesome-design-md 中的媒体深色方向，统一频道卡片、维护、巡检、记忆管理和手机配置页。见 DESIGN.md。

## 功能

- 内置央视、卫视及地方台公开节目单，支持 M3U、M3U8 和 TXT 导入、订阅更新与备用线路。
- 从公开电视台网页、播放器脚本、GET JSON 接口及 GitHub/GitLab/Jihulab 节目单目录发现候选；支持有上限的动态网页解析，实际媒体检查后加入。
- 停止播放后自动安排后台维护；观看优先，任务有时间、请求次数及存储上限。Android 待机、省电及强制停止会推迟任务。
- 视频画面巡检识别疑似无台标纯广告；普通电视台插播广告保留。两轮新证据确认后可自动屏蔽，并提供查看与解除入口。模型可能误判。
- 局域网临时扫码配置 API、密钥与订阅。入口默认关闭，随机配对令牌 10 分钟过期；密钥保存在设备中，不包含在源码和 APK 内。
- 结构化记忆和容量上限，避免保存聊天全文及截图文件。
- 内置 120 个原始台标图片，940 个频道名称/别名入口；自动补齐台标不调用 AI。下载缓存可选 2/5/10 MB。

![真实台标预览](screenshots/channel-logos.png)

模型推理使用用户自行配置的 HTTPS API，并非把模型权重放进 APK。节目源可用性取决于地区、运营商和来源状态。软件未实现登录、DRM、付费权限或运营商 IPTV 私网绕过；只处理公开可访问内容。

## 构建

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0；Gradle Wrapper 使用 8.6 并固定 SHA-256。

在本机创建未提交的 `local.properties` 指向 Android SDK，或设置 `ANDROID_HOME`。必要的网络代理请自行配置，本仓库不包含开发机器代理设置。

```sh
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

Windows 使用 `gradlew.bat`。输出为 `app/build/outputs/apk/release/app-release-unsigned.apk`，自行发布时请使用自己的签名；本项目不公开交付版本的签名私钥。

实际应用代码目录为 `app/src/kandianshi/java`，上游 `app/src/main/java` 保留用于追溯，不参与本分支 Java/Kotlin 编译。
