# iptv-org/iptv 订阅集成

来源：https://github.com/iptv-org/iptv 。官方分地区入口：https://iptv-org.github.io/iptv/countries/cn.m3u 。全部频道总表 index.m3u 可在上游找到，本 APP 采用分地区方式按需加载。

原本 TVList 已内置中国区源。本版把网络同步从旧固定源列表移到独立模块，避免同一中国区订阅重复请求；基础离线节目单仍保留。内置的国家目录由 https://iptv-org.github.io/api/countries.json 提供，本次取到250项，只保存代码及公开名称，约十几KB。该API项目和节目单使用Unlicense，既有 notices/iptv-org-iptv-LICENSE 保留；频道节目和标志属于相应权利人。目录只是来源数据，不代表服务授权或可播保证。

默认选择CN。电视频道管家可点选地区，或通过现有10分钟局域网二维码配置页选择；最多同时5项，清空可暂停该项目的自动同步。中国基础频道保留。切换选择触发同步安排，未选国际频道隐藏，当前播放地址受保护。

各地区每6小时重新获取公开M3U，失败15分钟后可重试。播放期间一次最多一个地区、下载上限512KiB；空闲时每份最多2MiB，大列表可能需要空闲时完成。缓冲或任务取消时停止下一步，网络失败不会清空已有频道。全部新地址仍进入既有候选队列，逐条验证后才显示；不把上游更新等同于网络可播。队列及已验证扩展各有1024条上限，验证速度受资源预算限制，大列表不会立即全部显示。

国际范围只在明确的地区导入时开启；常规解析继续按原国内规则。持久化国际分组和地区后缀，避免跨地区同名台混合。保留台标与不同查询参数；继续过滤购物、宗教、成人类别及内网/非HTTP等不支持的源。该规则不等同于画面广告识别，画面巡检仍采用既有模型及额度机制。

原有国内订阅、播放器、PHP协议原生解析、后台维护及合并写入一起使用；此项目不需要AI Key。电视需开机联网，系统强制停止和省电限制依然影响后台任务。

本次实际取到中国区156条EXTINF记录，这只是节目单条目数，不代表实际可播数。其他地区可用性受所在网络、地区和上游状态影响。最终测试与构建证据见 validation JSON，Android16及电视实机尚未测试。

按用户确认，默认只启用中国区，保持央视、卫视及地方台重点。实际快照导入检查：156条记录经国内规则合并为141个待验证频道，分组仅央视、卫视、地方台。该检查是节目单解析，不是141个频道逐条出画面验证。其他地区是可选设置，默认不启用。

轻量更新按最近尝试时间轮转，避免某个失败地区或来源长期占用首位。IPTV请求失败时继续给其他来源一次轻量更新机会；一旦视频缓冲仍立即让行。
