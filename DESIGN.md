# 看电视 design system
Reference: https://github.com/VoltAgent/awesome-design-md and https://getdesign.md/spotify/design-md
Adaptation, not a copy of Spotify branding. Media-first dark surfaces and green focus affordances.
Canvas #101214; panels #1A1E23; primary text #F5F7FA; secondary #A9B3BF; accent #53E0A0.
TV controls: minimum 52dp tall, 16sp labels, 28sp headings; 8dp spacing grid; 12dp corners.
Remote focus: 3dp mint outline, brighter fill, no layout shift. Preserve white-logo contrast plates.
Player remains unobstructed; maintenance has clear on/off state and explanatory captions. Pairing uses the same tokens on mobile.
